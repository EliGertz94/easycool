EasyCool — אתר תדמית רספונסיבי (HTML/CSS/JavaScript)

העלאה ל-Netlify:
1. חלצו את קובץ ה-ZIP.
2. היכנסו ל-app.netlify.com -> Add new project -> Deploy manually.
3. גררו את תיקיית easycool-site (או את תוכן התיקייה) לאזור ההעלאה.
4. ב-Netlify הוסיפו את easycool.co.il תחת Domain management ועקבו אחר הוראות DNS.
5. ב-BOX עדכנו את רשומות ה-DNS בהתאם להוראות Netlify. אל תעתיקו כתובות DNS ממדריך ישן.

לפני פרסום:
- פתחו את config.js והגדירו phoneDisplay, phoneDial, whatsappNumber.
- כל עוד המספרים ריקים, האתר אינו מחייג ואינו שולח קריאות; הטופס מציג הודעה מתאימה.
- טופס הדיווח פותח הודעת WhatsApp מוכנה, ולא שומר פרטים בשרת.
- האתר אינו מבטיח זמני הגעה או זמינות 24/7.
- בדקו שה-QR על המגנטים מוביל לדומיין הפעיל ונסרק ממגנט מודפס.
- מומלץ להוסיף פרטי עוסק, מדיניות פרטיות והצהרת נגישות מתאימה לפני השקה מסחרית.

כל הקבצים סטטיים. אין צורך ב-Node.js או בבסיס נתונים לגרסה זו.
